# plugin-publish-review — 作品审核

本插件提供 `publish` 服务，接收 [白纸](plugin-paper.md) 等插件提名的文件快照，执行静态检查、媒体元数据剥除、离线渲染与模型分类，通过后写入独立的公开存储根。它不负责 Cloudflare 部署；网址通知要等 [作品站](plugin-works-site.md) 核对上线。

## 配置与使用

```yaml
plugins:
  '@aalis/plugin-publish-review':
    manualReview: false
    textClassifier:
      provider: '<模型提供者实例 id>'
      model: '<模型 id>'
    imageClassifier:
      provider: '<具备视觉能力的模型提供者实例 id>'
      model: '<模型 id>'
    ownerTimeoutHours: 12
    ffmpegPath: ffmpeg
    chrome:
      headless: true
      executablePath: ''
```

`manualReview` 默认 `false`，表示自动审核通过的作品可继续发布，不要求每件作品人工批准。自动审核拒绝、拿不准或模型调用失败时，作品先被拦截并进入人工队列；审核者可查看自动结论和证据，再批准或拒绝。设为 `true` 时，自动审核通过的作品也须等待人工批准。结构检查或内容净化失败的作品始终阻断，不能由人工强行放行。关闭每件人工要求后，仅因该要求而等待的作品重新自动审核；自动未通过而转人工的作品继续等待裁决。

两个模型配置都按提供者与模型精确匹配。`imageClassifier` 留空时使用 `textClassifier`，该模型必须具有视觉能力。模型、浏览器或沙箱不可用时不会静默跳过检查。诊断页的 `publish-review.tools` 会指出缺少哪项能力。ffprobe 取 ffmpeg 的同级路径。

`limits` 默认每文件 25 MiB、每作品 50 文件且总计 50 MiB、最多 20 件待审、每来源 3 件待审、每来源 24 小时内 10 次提名。拒绝和撤回仍占已受理的每日提名配额。动态 PNG、动态 WebP 暂不接收；可转换为 GIF 或 MP4。视频的声音不由图像分类器审听，因此有音轨会判为需要进一步确认。

## 可见入口

在 WebUI「作品审核」查看待裁决、审核中、图像件、文件和历史。待裁决列表标明是配置要求人工审核，还是自动审核未通过后转人工，并显示自动审核的标记、分类结论和理由。审核者可批准、拒绝或打开本机隔离预览。拒绝通知不携带审核者写下的私有理由；分类模型的说明只展示在管理页，不作为宿主指令注入聊天。

隔离预览只监听运行 Aalis 的机器的 `127.0.0.1`，链接令牌不落盘，裁决、撤回、超时或停用后失效。预览中的作品脚本会运行；自动审核截图则关闭页面脚本。远程 WebUI 的用户不能把此链接当作远程预览地址。不要直接在本机打开下载的 HTML/SVG；下载文件没有预览服务添加的沙箱与响应头。

审核在应用启动后自动出队，热启用同样会启动。停用会中止在途流水、关预览和渲染器，并等待持久化操作；未完成的条目在下次启动重新处理。账本损坏时拒绝写入和裁决，不覆盖损坏文件。

## 数据与边界

审核快照、账本及审计记录位于 `pluginData:/publish-review/`，已通过的文件位于 `public:/<作品编号>/`。公开根不参与会话 checkpoint 回滚。公开文件每次读取均核对摘要。

作品页面仍可通过 WebRTC/STUN 或预连接建立额外的网络联系，不能承诺完全阻断浏览器的网络侧信道；分类器也不能证明内容绝无私人信息。详见[安全模型](../concepts/security-model.md)。

状态通知与审核结果一起进入持久化待发队列，在应用启动后注入消息事件，成功后才确认发送。失败或停机未送达的通知会在后续运行中重试；更晚的裁决会替换过时的待发状态。事件已经发送成功、但确认落盘前进程退出时可能重复通知，不承诺跨进程恰好一次。这里的确认表示事件总线完成调用监听者，不表示下游监听者处理成功，也不等于聊天平台或最终用户确认收到。
