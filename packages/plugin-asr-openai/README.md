# @aalis/plugin-asr-openai

语音识别（ASR）—— OpenAI Whisper API 提供者

## 安装

```bash
pnpm add @aalis/plugin-asr-openai
```

## 提供 / 依赖

`definePlugin` 默认导出：

- provides：`asr`
- uses：`logger`、`config`、`provide`；可选 `proc`（`process`）、`storage`
