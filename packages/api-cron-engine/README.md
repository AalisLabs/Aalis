# @aalis/api-cron-engine

Cron 引擎服务契约：解析与订阅 cron / `@every` 表达式。

## 安装

```bash
pnpm add @aalis/api-cron-engine
```

## 提供

服务描述符：`cronEngine`（服务名 `cron-engine`）。

```ts
import { cronEngine } from '@aalis/api-cron-engine';
```

实现见 `@aalis/plugin-cron-engine`。
