# @aalis/api-flow-control

流控服务契约：会话计数、冷却、限速与闲置触发状态。

## 安装

```bash
pnpm add @aalis/api-flow-control
```

## 提供

服务描述符：`flowControl`（服务名 `flow-control`）。

```ts
import { flowControl } from '@aalis/api-flow-control';
```

实现见 `@aalis/plugin-flow-control`。
