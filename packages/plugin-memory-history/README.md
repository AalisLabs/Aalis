# @aalis/plugin-memory-history

跨会话消息历史上下文（基础记忆）

## 安装

```bash
pnpm add @aalis/plugin-memory-history
```

## 提供 / 依赖

`definePlugin` 默认导出：

- provides：无
- uses：`memory`、`config`、`logger`、`contributions`；可选 `tools`
