# @aalis/plugin-image-sender

图片发送：将生成/本地图片经平台发出

## 安装

```bash
pnpm add @aalis/plugin-image-sender
```

## 提供 / 依赖

`definePlugin` 默认导出：

- provides：无
- uses：`events`、`logger`；可选 `tools`、`storage`、`media`、`memory`、`archive`（`message-archive`）
