# @aalis/plugin-draw

让纯文本模型画图：SVG/HTML 标记渲染为图片与 GIF 动图（无头浏览器 + ffmpeg）

## 安装

```bash
pnpm add @aalis/plugin-draw
```

## 提供 / 依赖

`definePlugin` 默认导出：

- provides：无
- uses：`logger`、`lifecycle`、`config`；可选 `tools`、`storage`、`processService`（`process`）
