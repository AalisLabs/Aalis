# @aalis/api-media

多模态媒体识别契约：图像 / 音频 / 视频处理为文本。

## 安装

```bash
pnpm add @aalis/api-media
```

## 提供

服务描述符：`media`（服务名 `media`）。

```ts
import { media } from '@aalis/api-media';
```

实现见 `@aalis/plugin-media`。
