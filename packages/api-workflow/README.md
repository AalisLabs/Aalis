# @aalis/api-workflow

工作流服务契约：触发器、DAG 节点与运行实例类型。

## 安装

```bash
pnpm add @aalis/api-workflow
```

## 提供

服务描述符：`workflow`（服务名 `workflow`）。

```ts
import { workflow } from '@aalis/api-workflow';
```

实现见 `@aalis/plugin-workflow`。
