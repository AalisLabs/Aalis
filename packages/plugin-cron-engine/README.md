# @aalis/plugin-cron-engine

Cron 定时引擎：解析与触发 cron 表达式任务

## 安装

```bash
pnpm add @aalis/plugin-cron-engine
```

## 提供 / 依赖

`definePlugin` 默认导出：

- provides：`cronEngine`（服务名 `cron-engine`）
- uses：`provide`、`logger`、`lifecycle`
