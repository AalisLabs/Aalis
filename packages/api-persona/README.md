# @aalis/api-persona

人格服务契约：角色卡、输出格式与会话人格选项。

## 安装

```bash
pnpm add @aalis/api-persona
```

## 提供

服务描述符：`persona`（服务名 `persona`）。

```ts
import { persona } from '@aalis/api-persona';
```

实现见 `@aalis/plugin-persona`。
