# @aalis/api-doctor

诊断子系统契约：检查项注册、报告类型与 `doctor` 描述符。

## 安装

```bash
pnpm add @aalis/api-doctor
```

## 提供

服务描述符：`doctor`（服务名 `doctor`）。

```ts
import { doctor } from '@aalis/api-doctor';
```

实现见 `@aalis/plugin-doctor`。
