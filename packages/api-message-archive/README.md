# @aalis/api-message-archive

消息归档服务契约：入站消息与平台通知落档。

## 安装

```bash
pnpm add @aalis/api-message-archive
```

## 提供

服务描述符：`messageArchive`（服务名 `message-archive`）。

```ts
import { messageArchive } from '@aalis/api-message-archive';
```

实现见 `@aalis/plugin-message-archive`。
