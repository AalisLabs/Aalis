# @aalis/plugin-asr-whisper-cpp

语音识别（ASR）—— 本地 whisper.cpp 提供者

## 安装

```bash
pnpm add @aalis/plugin-asr-whisper-cpp
```

## 提供 / 依赖

`definePlugin` 默认导出：

- provides：`asr`
- uses：`logger`、`config`、`provide`、`proc`（`process`）、`storage`
