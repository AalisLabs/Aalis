# @aalis/plugin-reach

触及：按一次工具调用签发触及凭据（契约见 `@aalis/api-reach`）。发起类别取权限服务的 `originOf`，房间类别、档位与越界策略、绑定取会话管理里的记录，三张受保护清单在激活时按家目录布局与真实路径算好，交给 `resolveReach` 定上限：只有 owner 在自己的会话里有本地效果，子任务随发起它的那一轮父会话。另管本会话临时区（建、随会话删、定期清扫）、子进程环境（owner 的 login shell 环境，沙箱内去掉凭据）、会话的污点与白纸的来源账本。

## 角色

运行时插件，提供 `reach` 服务。

## 安装

```bash
pnpm add @aalis/plugin-reach
```

参考 [docs/plugins/plugin-reach.md](../../docs/plugins/plugin-reach.md) 与 [docs/api/api-reach.md](../../docs/api/api-reach.md)。
