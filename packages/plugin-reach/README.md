# @aalis/plugin-reach

触及：按一次工具调用签发触及凭据（契约见 `@aalis/api-reach`）。主体取权限服务的 `principalOf`，场所与绑定取会话管理里的记录，档位与越界策略固定，三张受保护清单在激活时按数据目录布局与真实路径算好，交给 `resolveReach` 定上限：主体是 owner 的调用有本地效果，不看会话的受众（主体的判法见权限服务的 `principalOf`：续做与子任务的类别随起它的那一轮，参与者按这次调用的）。另管本会话临时区（建、随会话删、定期清扫）与子进程环境（owner 的 login shell 环境，沙箱内同样完整，只去掉本实例的变量与 ssh-agent 的 socket）。

## 角色

运行时插件，提供 `reach` 服务。

## 安装

```bash
pnpm add @aalis/plugin-reach
```
