# @aalis/plugin-prompt-budget

提示词预算：token 计数与上下文裁剪自检

## 安装

```bash
pnpm add @aalis/plugin-prompt-budget
```

## 提供 / 依赖

`definePlugin` 默认导出：

- provides：无
- uses：`events`、`lifecycle`、`logger`；可选 `tools`
