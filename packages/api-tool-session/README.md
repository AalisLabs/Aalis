# @aalis/api-tool-session

会话历史服务契约：统一读历史入口与平台访问控制。

## 安装

```bash
pnpm add @aalis/api-tool-session
```

## 提供

服务描述符：`sessionHistory`（服务名 `session-history`）。

```ts
import { sessionHistory } from '@aalis/api-tool-session';
```

实现见 `@aalis/plugin-tool-session`。
