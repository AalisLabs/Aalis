# @aalis/plugin-i18n

`i18n` 服务的默认提供者：按读者的语言链渲染文字对象，收语言包。契约见 `@aalis/api-i18n`，文字对象与字典见 `@aalis/schema-i18n`。

- provides：`i18n`
- uses：`provide`、`events`、`config`；`contributions`、`doctor`、`session-manager`、`session-settings`、`host-config`、`webui-server` 可选
- 语言链：一律经 `@aalis/schema-i18n` 的 `normalizeLanguages` 规范化、去重（只看前 32 项，最多 8 种）。`sessionId` 读者按根会话（子会话跟根会话）：根是房间的取房间的 `language`（经会话设置的读取器按层解析），根是 owner 会话（会话种类为 owner，WebUI 与终端的会话）的与 `host` 读者一样取全局层；会话不存在的按会话 id 与入口平台解析。会话设置缺席时只取本插件配置里的值。日期与时间按服务进程的时区。
- 配置 `language`：可按会话覆盖的插件配置字段（全局层就是这里，作者默认 `['en']`），有序多选（`ordered`），可选项来源是 `i18n-languages`，显眼程度 common，只适用于房间（owner 会话按全局层，子会话跟根会话，所以不列这一项、建子会话时也不写下），1 级能改。规范化之后不合法的语言标签拒收（与读的一侧同一个规范化，`zh_CN` 这类系统写法收下，读时整理成 `zh-CN`）；完全相同的重复项去掉，写法不同的同一语言读时规范化后去重。
- 语言包：取贡献点 `i18n:pack` 的全部交付建索引，同一语言按全局键（包名在前）取先。用时与贡献点对照，交付变了才重建，运行中的交付与撤回立即生效；形状不对或读取时抛错的包跳过。贡献点缺席时没有语言包。
- `languages()`：目录里各字典的原文语言与译文语言、语言包的语言，按标签排序，带自称（`Intl.DisplayNames`，取不到时用标签）。
- 可选项来源 `i18n-languages`：经贡献点 `webui:options` 交出，值是 `languages()` 的语言标签，标签是自称。
- 诊断 `config/i18n.languages`（装了 doctor 时登记）：各层（读取器的 `layers()`：全局层、平台档、平台类型档、场所；只看收这一项的窗口场所，会话自己的设置不查）写的语言列表里，有某一项没有任何字典或语言包提供时，每项一条 warn，与渲染同一判法（语言与文字相同的，再语言相同的：`en-US` 有 `en` 就算提供，`ja-JP` 没有任何日语就不算）。结论写明是哪一层（全局层不写）与实际用的语言（按这一层的列表、照渲染的选法在全部可用语言里选），如「语言列表里的 日本語 (日本) 没有插件提供，实际用 中文（中国）」「平台档 onebot里的 日本語 没有插件提供，实际用 English」；详情写怎么办：装语言包（npm 关键词 `aalis-lang-<标签>`，先完整标签、再基础语言），或在会话设置的这一层里调整语言列表。都有提供时一条 ok。只提示，渲染照常按列表往后找。
- 「需要处理」（装了 webui-server 时）：上面诊断的每条 warn 各一项（id 为 `i18n.languages.<序号>`，结论与详情同诊断），不必先跑诊断。会话设置变了（`session-settings:changed`）、宿主配置文档变了（`host-config:changed`）、插件变了（`plugins:changed`，语言包与字典随插件交付与撤回）时重算，都有提供时撤回；运行中不随插件变动的语言包交付与撤回要等下一次重算才反映。
- 「翻译」页（插件位置）：按 ns 列出每种语言的已译、缺、过时（语言包里原文改过措辞的）、冲突（目录记下的再登记冲突，与几个语言包给同一条的不一样）与坏条目（`checkTexts` 报的问题）；选中一行给出具体的键与两种待译骨架：插件自己的 `src/locales/<语言>.ts`，与语言包的 `entries`（带 `from`）。

没装本插件时，各出口按原文显示。
