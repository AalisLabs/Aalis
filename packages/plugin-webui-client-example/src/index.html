示例前端 · webui-client-example

你正在看「第二前端」

这是一个最小的演示前端。能看到它，说明 Aalis 的「忒修斯之船——前端可热切换」整条链路是通的：

  1. 它的 package.json 标了 aalis.client: true，被 webui-server 动态发现（没有任何硬编码包名）；
  2. 前端就是 webui-client 服务的多个 provider——你在默认前端设置「系统」的服务偏好里，把 webui-client 一行选成它；
  3. webui-server 重挂静态目录并广播刷新（servicePreferences 持久化），页面平滑 reload 后由它接管。

切回默认前端：本页没有切换入口，打开 /__clients 恢复页选回 @aalis/plugin-webui-client； 回到默认前端后，也可以在设置「系统」的服务偏好里把 webui-client 一行恢复默认。

Example frontend · webui-client-example

You are looking at a “second frontend”

This is a minimal demo frontend. Seeing it means the whole “Ship of Theseus: hot-swappable frontends” chain in Aalis works:

  1. Its package.json sets aalis.client: true, so webui-server discovers it dynamically (no package name is hard-coded);
  2. frontends are providers of the webui-client service: in the default frontend’s service preferences under Settings “System”, set the webui-client row to this one;
  3. webui-server remounts the static directory and broadcasts a refresh (servicePreferences is persisted); after a smooth reload, this page takes over.

To switch back to the default frontend: this page has no switcher, so open the /__clients recovery page and choose @aalis/plugin-webui-client; once back on the default frontend, you can also restore the webui-client row to its default in the service preferences under Settings “System”.
